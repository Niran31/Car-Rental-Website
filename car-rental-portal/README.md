# DriveX Car Rental Portal

A responsive Next.js prototype containing both customer and admin experiences.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Included
- Customer landing/search/fleet UI
- Vehicle filtering
- Booking modal and simulated confirmation
- Booking state shared with admin dashboard
- Admin dashboard
- Fleet management with add vehicle and availability toggle
- Bookings, customer, payments and reports module placeholders
- Responsive desktop/mobile layouts
